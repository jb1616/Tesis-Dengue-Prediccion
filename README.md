# Tesis: Predicción de Dengue en Perú

Código en Python desarrollado en Google Colab para el análisis y modelo de predicción de casos de dengue.

## Archivos
* Trabajo_Dengue.ipynb: Cuaderno con la carga de datos, limpieza, análisis exploratorio y modelado.
